I own production data systems end to end — the pipeline, the governance, the proof, and the team that runs it.

My lens is silent failure: green jobs with wrong data, stale dimensions, duplicate identities. I find what monitoring misses — with parity checks and dollar totals, not alerts.

Senior AI Data Engineer at VaynerX, NYC. I write **THE DELTA**, a daily data engineering newsletter, and build in public at [@jugal.builds](https://www.instagram.com/jugal.builds).
